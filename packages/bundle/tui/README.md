# `@deepseek-ai/dsh-tui`

English | [中文](README.zh.md)

The dsh interactive terminal bundle. The `dsh` launcher boots this profile when `--profile` is omitted. [`cordis.patch.yml`](cordis.patch.yml) rides directly over [`dsh-base`](../base/README.md): it supplies the coding persona and tool mode, disables HMR, mounts Code Mode's worker as a core execution capability, and inserts this package's `tui-runtime` plugin (config `{resume, theme}`, resolved from the injected `tuiStartup` provider). It mounts no Host, HTTP server, Web runtime, or browser plugin.

After the Loader settles, the runtime reads the shared [`ctx.agentDefaultModel`](../../core/agent-default-model/README.md), creates or resumes one persisted Agent through `ctx.agents`, and owns the TTY through [`@oh-my-pi/pi-tui`](https://www.npmjs.com/package/@oh-my-pi/pi-tui). The Node `dsh` launcher re-execs this profile under bun >= 1.3.14; missing bun is a usage error before the TTY check. The session layout follows Pi's interactive TUI with OMP chrome: a colored product header with key hints, a transcript of a user-message bubble, dim Thinking blocks for `reasoning-delta`, Markdown assistant blocks, and [`presentCall` / `presentResult`](../../core/tools/README.md) tool cards, and one live card per `subagent/start` — labelled from the child log's `subagent/descriptor`, folding the child session's own tool activity into a rolling feed, and settling with the run's stop reason on `subagent/end` — a muted rounded-border editor, and a cwd/model footer that also counts running subagents and, once the first turn reports token usage, inserts a dim durable stats row above the model row showing cache-hit percent, billed input and output tokens, decode throughput in tok/s, turn count, and context occupancy (`ctx N% used/window`), all read from the `token-meter` and `session-stats` session projections so the figures survive paging and compaction. A spinning `Thinking` loader ticks at the transcript tail while the Agent waits for the model; the first reasoning or answer token, and a pending tool card, replace it. A settled subagent run rings BEL; live runs set the window title to `dsh · N subagent(s) running`. A `card: 'diff'` call (write, edit, `str_replace_editor`) paints `+`/`-` hunks collapsed to eight rows; Ctrl+O expands the last tool card and Alt+O opens a fullscreen overlay the mouse wheel can scroll. The editor and footer sit on the last rows of the TTY until the transcript fills the viewport. `/model` (also Ctrl+P / Alt+P) lists registered `ctx.llm` routes — DeepSeek official, settings-configured pi-ai profiles, installed-catalog providers whose ambient API keys are already set, and Ollama Cloud when `OLLAMA_API_KEY` is set — and, when a selected model exposes selectable reasoning efforts, opens a second picker for the effort level before writing the live selection and persisting it through `agentDefaultModel.saveSelection`. The footer appends the current effort as `· <effort>`. An `llm/adapters-updated` commit rebuilds an open `/model` picker and notices newly registered provider ids, so a `dsh login` in another process appears without restarting the TUI. `/theme` lists the built-in palettes Dark, Tokyo Night, Catppuccin, and Light plus `$DSH_HOME/themes/<id>.json` files (oh-my-pi JSON with `colors` / `vars` is accepted for this token set), applies the live palette, and persists the id in the `tui-theme` settings section. Typed lines become ordinary user messages; idle Enter paints the user bubble immediately and starts a follow-up turn; while a turn is running, Enter steers the text into that turn at the next step, shown as a dim `appending` line until claimed. Lines beginning with `/` stay in the [`dsh-commands`](../../interaction/commands/README.md) command plane (`/help`, `/model`, `/theme`, `/exit`, and `/quit` are registered here). Ask-user prompts use [`dsh-user-questions`](../../interaction/user-questions/README.md) overlays. An `approval/request` for this session opens an Allow once / Reject overlay on [`ctx.approval`](../../interaction/user-approval/README.md); Escape cancels. Ctrl+C cancels a running Agent and exits when idle; Ctrl+D exits. Teardown stops pi-tui, drains input, flushes the Session, and requests exit through the launcher-provided `ctx.appExit` host hook ([`dsh-cmdline`](../../boot/cmdline/README.md)). A missing TTY is a usage error. The invocation is this app's command line: the ordinary `tui-startup` provider ([`src/startup.ts`](src/startup.ts)) injects `ctx.cmdlineArgs`, reads `--resume` / `--session`, prints the app's `--help`, and provides `tuiStartup`; the runtime injects that service and reads its resume id from lazy config.

## Model Experience

None, as the runtime submits typed lines as ordinary user messages; prompts and tools belong to the base and tui bundle rows.

#### KV Cache effect

None; the runtime adds nothing to the request prefix.

## Known Limitations and Deferred Work

- **Theme files are not watched** — `/theme` re-reads `$DSH_HOME/themes` when the picker opens; editing a selected JSON does not live-reload. There is no OSC 11 auto dark/light switch and no bundled oh-my-pi default pack.
- **One session per process** — the runtime does not list or switch sessions; `--resume` names an id the persistence backend already holds.
- **No live skill-catalog completions** — slash autocomplete reads `dsh-commands` only; skill names are not suggested from `ctx.skills`.
- **Interactive `dsh` requires bun >= 1.3.14** — `dsh web` and `dsh --profile headless` stay on Node; dump-config and launcher `--help` do too.
- **Context breakdown is not displayed** — the footer shows total context occupancy (`ctx N% used/window`) but not the `system` / `tools` / `messages` split the `contextBreakdown` projection folds.
- **Context occupancy appears only after the first request** — `contextWindow` is read from the first `request/context` record, not preheated from `resolveModelInfo`, so the `ctx` group stays empty before the first billed turn reports a sample.
- **Subagent cards are live-only** — the `subagent/start` / `subagent/end` lifecycle is transient, so `--resume` replays the delegation's durable tool call and result but not the run's activity feed.
- **`ctx.appExit` is launcher-owned** — booting the tui profile outside the `dsh` launcher fails loud at activation until the host provides the exit request.
